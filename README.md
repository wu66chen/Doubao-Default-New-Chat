# 豆包默认新对话-油猴脚本
完美解决豆包网页版强制跳转“豆包”默认对话的问题！让你每次打开豆包，都能自动拦截“豆包”对话，强制开启清爽的全新空白对话。小白友好，全程免改代码，安装即用！

## 为什么你需要这个脚本？
如果你习惯了 ChatGPT 那种“打开即是白板”、“一事一议”的生产力体验，豆包的默认逻辑绝对会让你抓狂：只要你在地址栏输入 `doubao.com`，官方会强制将你重定向到“豆包”这个对话里，会有很多无用信息干扰你。

## 核心特色功能
- **傻瓜式智能配置**：彻底告别改代码！首次运行自动弹窗引导配置。安装脚本后立即打开doubao.com，脚本会自动提取填好你的“豆包”对话 ID，你只需点一下确认。
- **极速拦截无感切换**：一旦检测到网页企图跳转到你设定的对话 ID，会在 0.5 秒内自动发送 `Ctrl+K` 指令瞬间拉出新对话，旧对话不留丝毫痕迹。
- **超强容错与兜底**：哪怕官方未来改版隐藏了按钮，内置的快捷键驱动依然可用。手残党不小心粘贴了长串网址进配置框？没关系，脚本会自动剔除多余字符精准提取 ID。
- **随时可修改**：支持在油猴插件菜单中点击该脚本下方的“⚙️ 重新设置拦截 ID”进行更改。

## 🛠️ 安装与使用教程
1. 安装本脚本。
2. 在浏览器地址栏打开 `https://www.doubao.com/`。
3. 此时网页会弹出一个配置提示框。因为你当前就在“豆包”对话页面，输入框里已经自动提取并填好了当前的“豆包”对话 ID，点击【确定】即可！

大功告成！下次再打开豆包，享受永远干净纯粹的新对话吧！

## 💬 Q&A
**问：如果不小心把拦截 ID 填错了怎么办？**
答：点击浏览器右上角的 Tampermonkey（油猴）插件图标，找到该脚本下方的“⚙️ 重新设置拦截 ID”即可进行更改。

**问：我想进入“豆包”对话怎么办？**
答：点击油猴插件图标，将本脚本的开关临时拨到“关闭”状态，刷新页面即可正常进入。
